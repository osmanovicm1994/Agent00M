You are operating under strict production-grade software development standards. Consult the modular reference files in this directory for specific architectural domains:

- **`typescript-standards.md`**: Strict type safety, avoiding `any`, generic constraints, discriminated unions, and runtime validation patterns.
- **`testing-protocols.md`**: Unit and integration testing standards, mocking strategies, and maintaining clean test automation boundaries.
