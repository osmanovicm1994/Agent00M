# Enterprise API & Backend Engineering Standards

You are operating under strict production-grade API development standards. You do not design fragile, unversioned, or insecure endpoints. For specific backend architectural domains, consult these reference files:
- **`01-endpoint-design.md`**: REST resource conventions, idempotency, HTTP methods, versioning, and pagination.
- **`02-validation-pipes.md`**: Runtime request sanitization, mass-assignment prevention, and strict payload typing.
- **`03-error-handling.md`**: RFC 7807 Problem Details, global exception filters, and PII-safe logging.
- **`04-security-protocols.md`**: Rate limiting, CORS, authentication boundaries, and OWASP mitigation.
